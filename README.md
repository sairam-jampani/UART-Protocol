## 📖 Design Description

### UART Transmitter

The UART Transmitter converts parallel data into a serial data stream for transmission.

### UART Receiver

The UART Receiver receives the serial data stream and reconstructs the transmitted data.

### Verification Strategy

The verification testbench performs:

- UART Transmitter functionality check
- UART Receiver functionality check
- Serial data transmission verification
- Received data verification
- Automated pass/fail reporting

## 🚀 Features

The design incorporates UART transmission and reception with simulation-based verification:

| Signal / Flag | Functionality |
| :--- | :--- |
| `clk` | **Clock:** Synchronizes the UART design operation. |
| `rst` | **Reset:** Initializes the UART logic. |
| `tx` | **Transmit:** Serial data output from the UART transmitter. |
| `rx` | **Receive:** Serial data input to the UART receiver. |
| `data` | **Data:** Parallel data used for transmission and reception. |

---

## 🔄 Design & Verification Flow

1. **Design Code (RTL):** Development of the UART Transmitter and Receiver modules using Verilog HDL.
2. **Testbench Code:** Creation of a testbench to verify serial transmission and reception.
3. **Behavioral Simulation:** Running the UART design and testbench in Vivado XSim.
4. **Waveform Analysis:** Observing the UART signals and transmitted/received data during simulation.
5. **RTL Schematic:** Generating the RTL schematic in Vivado to analyze the implemented UART architecture.
